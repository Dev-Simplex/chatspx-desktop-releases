# chatspx-desktop-releases

Instaladores publicados do app de Windows do Chat SPX. Este repositório não tem código-fonte:
o código fica no repositório privado `chatspx-desktop`.

Cada release é gerada pelo GitHub Actions do `chatspx-desktop` a partir de uma tag `v*` e traz o
instalador (`.exe`), o `latest.yml` e o `min-version.json`, lidos pelo atualizador automático do app.

Para baixar a versão mais recente, abra **Releases** e baixe o arquivo `.exe`.
